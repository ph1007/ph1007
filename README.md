### 📌 Projetos em Destaque

#### 🌊 **AcquaScan — Sistema Inteligente de Análise & Monitoramento Hídrico**
*Projeto em desenvolvimento em equipe para a competição oficial do SEBRAE (Entrega: 20 de Outubro).*
- **O que é:** Solução tecnológica completa focada em análise e monitoramento hídrico, combinando hardware, software e aplicação móvel.
- **Engenharia & Tecnologias:** Uso de sensores hídricos integrados via **Arduino (C)**, display para exibição de dados em tempo real, banco de dados, **APIs** de integração e prototipagem de maquete funcional representativa.
- **Desenvolvimento de App:** Produção de um aplicativo móvel funcional integrado à solução para gestão dos dados.
- **Visibilidade:** Projeto selecionado para competir em programa oficial do **SEBRAE**.
- **Repositório do Grupo:** 🔗 [Acompanhar Projeto no GitHub](https://github.com/Mateus-Fonseca847/acquascan-BMC)
